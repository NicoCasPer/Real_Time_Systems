## Control On-Off

```
Lee POT → Mapea a umbral [0-100]°C → Lee Temperatura → Compara → Conmuta LED
```

Si `T_actual > T_umbral` → LED ON, si no → LED OFF

## Comando UART

```
THRESHOLD
→ umbral=XX°C | LED=ON/OFF | T_actual=YY.YY°C
```

## Sincronización Thread-Safe

Todas las actualizaciones del umbral y estado del LED están protegidas con mutex `s_state_mutex`.
